Infrastructure / DevOps Engineer

Job Requirements:

  • Provision and manage bare metal servers
  • Migrate existing infrastructure to improved setup
  • Build monitoring systems for server infrastructure
  • Implement backup and recovery procedures
  • Create automation scripts for server and node management
  • Upgrade legacy Docker containers and optimize resource usage

Required Skills:

  • Extensive bare metal server management experience
  • Deep Linux/Unix systems administration
  • Strong scripting abilities (Bash, Python)
  • Proficient in Ansible for configuration management
  • Knowledge of distributed systems and high availability design
  • Docker experience with legacy system upgrades
  • Security-focused server management approach
  • Experience with data backup and recovery procedures

Preferred Experience:

  • Server monitoring tools (Prometheus, Grafana)
  • Infrastructure best security practices
  • Legacy infrastructure migration experience
  • Kubernetes knowledge

Project Details:

Remote work, flexible hours, must coordinate with the existing development team. Must create documentation for handoff to internal team.

Cloud DevOps Specialist (EVM Focus)

Core Responsibilities:

  • Automate GCP infrastructure deployment using Pulumi
  • Integrate and manage third-party blockchain APIs (Alchemy, Infura, CoinAPI)
  • Build monitoring and observability for cloud-based blockchain services
  • Implement CI/CD workflows for containerized applications
  • Optimize cloud costs and scaling for EVM blockchain operations

Required Skills:

  • Strong Google Cloud Platform experience
  • Proficiency in Pulumi or Terraform for infrastructure as code
  • Experience with third-party API integration and management
  • Container orchestration knowledge (Docker, potentially Kubernetes)
  • Understanding of CI/CD workflows (GitHub Actions, GitLab CI)
  • Cloud-native monitoring and logging experience
  • Cost optimization experience for cloud infrastructure

Nice to Have:

  • Familiarity with Ethereum and EVM-compatible blockchains
  • Experience with blockchain API providers (Alchemy, Infura)
  • Knowledge of cryptocurrency wallet infrastructure
  • Understanding of Web3/DeFi applications

Project Focus:

  • Handle all EVM-compatible blockchains (Ethereum, Polygon, BSC, etc.)
  • Implement automated scaling for API usage
  • Build cost-effective cloud infrastructure for blockchain data
  • Create monitoring dashboards for API usage and costs

Bare Metal DevOps Specialist (UTXO Focus)

Core Responsibilities:

  • Provision and manage Hetzner bare metal servers
  • Deploy and maintain full blockchain nodes (Bitcoin, Litecoin, Dogecoin, etc.)
  • Build monitoring systems for bare metal infrastructure
  • Implement backup and disaster recovery for blockchain data
  • Create automation tools for server management and node operations

Required Skills:

  • Extensive bare metal server management experience, preferably Hetzner
  • Deep Linux/Unix systems administration knowledge
  • Experience with blockchain node operations and maintenance
  • Strong scripting abilities (Bash, Python)
  • Proficient in Ansible for configuration management and deployment
  • Security-focused approach to server management
  • Experience with large-scale data backup and recovery

Nice to Have:

  • Specific experience with Bitcoin Core and other UTXO blockchain nodes
  • Understanding of blockchain synchronization and data requirements
  • Experience with server monitoring tools (Prometheus, Grafana)
  • Knowledge of cryptocurrency infrastructure security best practices

Project Focus:

  • Handle all UTXO-based blockchains (Bitcoin, Litecoin, Dogecoin, etc.)
  • Optimize server utilization and costs on Hetzner infrastructure
  • Build reliable backup systems for critical blockchain data
  • Create simple monitoring interfaces for non-technical team management
